# 安装、使用与真机验证

从 Releases 下载 APK 后安装。Android 如提示安装来源限制，只需为你实际用于安装的浏览器或文件管理器临时允许安装，完成后可关闭。

1. 将手机和手环放在身边，保留小米运动健康正常连接。
2. 环迹 → 添加我的手环 → 授予附近设备与精确位置。不要只授权模糊位置。
3. 核对蓝牙名称/地址后选择自己的设备。同名不能证明是同一只手环。
4. 开启系统定位和蓝牙，点击开启守护。首次观测成功后才启用失联计时。
5. 等待有效定位。室内可能只有检测时间；到室外重试。
6. 在系统设置允许通知；按手机品牌检查电池限制。首版不会自动开机启动。

若官方 App 连接时完全看不到广播，不要为了让环迹看起来正常而删除官方配对。请记录此兼容性结果；本版本可能不适用你的固件。

## 常见情况

- **等待首次检测**：还没在本次守护看到目标，不会发失联警报；两分钟后会停止并提示诊断。
- **暂未检测到**：可能离开、广播暂停、地址改变；请检查手环，不能据此断定丢失。
- **守护中断**：重新确认蓝牙、定位、权限和电池设置，再手动开启。
- **无通知**：系统通知权限、通知渠道和勿扰模式会影响提示与声音。
- **找不到地图 App**：选择已安装地图或复制坐标；未针对全部地图提供兼容保证。
